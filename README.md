# 🚀 DISBATTERY TRADE - App para Mercaderistas

## 📱 Aplicación Web Progresiva (PWA) para Gestión de Rutas y Visitas

**DISBATTERY TRADE** es una aplicación completa diseñada específicamente para mercaderistas de Disbattery, que permite gestionar rutas, realizar visitas, capturar información de clientes y generar reportes detallados de manera eficiente, tanto online como offline.

---

## 🎯 **FUNCIONES PRINCIPALES**

### 👤 **PARA MERCADERISTAS**

#### 📍 **1. GESTIÓN DE RUTAS**
- **Mi Ruta**: Visualización de la ruta diaria asignada
- **Navegación GPS**: Integración con Google Maps para navegación punto a punto
- **Estado en tiempo real**: Seguimiento del progreso de la ruta (Planificada → En Progreso → Completada)
- **Puntos de visita**: Lista ordenada de clientes a visitar con información detallada
- **Tiempo estimado**: Cálculo automático del tiempo total de la ruta

#### 🏪 **2. TIPOS DE VISITAS**

##### 🛍️ **MERCHANDISING**
- **Captura de señalización**: Fotografía y evaluación de material publicitario
- **Inventario de productos**: Registro de productos Shell y Qualid disponibles
- **Material POP**: Verificación y colocación de material punto de venta
- **Competencia**: Análisis de productos de la competencia
- **Recomendaciones**: Sugerencias para mejorar la exhibición

##### 🎪 **TRADE - EVENTOS**
- **Eventos especiales**: Gestión de activaciones y eventos promocionales
- **Múltiples marcas**: Soporte para eventos Shell y Qualid
- **Duración flexible**: Eventos de uno o varios días
- **Ubicaciones específicas**: Eventos en centros comerciales, ferias, etc.

##### 💼 **TRADE - IMPULSO**
- **Ventas directas**: Registro de ventas de productos específicos
- **Impulso de marca**: Actividades de promoción directa
- **Productos premium**: Enfoque en productos de alto valor
- **Metas de venta**: Seguimiento de objetivos comerciales

#### 📊 **3. CAPTURA DE INFORMACIÓN**

##### 📷 **SHELL - MERCHANDISING**
- **Exhibidores Shell**: Verificación y fotografía de exhibidores
- **Afiches y material**: Inventario completo de material publicitario
- **Banderines**: Conteo y estado de banderines promocionales
- **Avisos acrílicos**: Verificación de señalización permanente

##### 🔧 **QUALID - MERCHANDISING**
- **Productos Qualid**: Inventario específico de lubricantes Qualid
- **Material promocional**: Verificación de material punto de venta Qualid
- **Exhibición**: Evaluación de la presentación de productos
- **Competencia**: Análisis comparativo con otras marcas

#### 📝 **4. FORMULARIOS INTELIGENTES**
- **Autocompletado**: Información del cliente pre-cargada
- **Validación en tiempo real**: Verificación de datos mientras se capturan
- **Fotos obligatorias**: Sistema que requiere evidencia fotográfica
- **Geolocalización**: Captura automática de coordenadas GPS
- **Modo offline**: Funcionamiento completo sin conexión a internet

#### 🔄 **5. SINCRONIZACIÓN AUTOMÁTICA**
- **Almacenamiento local**: Datos guardados en el dispositivo
- **Sincronización inteligente**: Envío automático cuando hay conexión
- **Respaldo seguro**: Múltiples copias de seguridad de los datos
- **Recuperación de errores**: Sistema robusto ante fallos de conexión

## 📋 **FLUJO DE TRABAJO TÍPICO**

### 🌅 **INICIO DEL DÍA**
1. **Login**: Autenticación con credenciales
2. **Verificación de ruta**: Revisión de clientes asignados
3. **Descarga offline**: Sincronización de datos para trabajo sin conexión
4. **Inicio de ruta**: Cambio de estado a "En Progreso"

### 🚗 **DURANTE EL RECORRIDO**
1. **Navegación GPS**: Ir al siguiente cliente
2. **Check-in**: Registrar llegada con geolocalización
3. **Selección de visita**: Merchandising, Trade Eventos o Trade Impulso
4. **Captura de datos**: Formularios específicos según tipo de visita
5. **Evidencia fotográfica**: Fotos obligatorias de productos y señalización
6. **Finalización**: Completar visita y continuar al siguiente punto

### 🌆 **FIN DEL DÍA**
1. **Finalizar ruta**: Marcar ruta como completada
2. **Sincronización**: Envío automático de todos los datos
3. **Reportes**: Generación automática de informes
4. **Notificaciones**: Confirmación a administradores

## 🔧 **INSTALACIÓN PARA DESARROLLADORES**

### **Requisitos**
```bash
Node.js 18+
npm o yarn
Firebase CLI
```

### **Configuración Local**
```bash
# Clonar repositorio
git clone https://github.com/Dioscar-DEV/DISBATTERY-TRADE.git
cd DISBATTERY-TRADE

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env.local
# Editar .env.local con tus claves de Firebase

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Deploy a Firebase
firebase deploy
```

### **Estructura del Proyecto**
```
src/
├── app/                    # Páginas de la aplicación
│   ├── admin/             # Panel de administración
│   ├── mi-ruta/           # Ruta del mercaderista
│   ├── visit-capture/     # Captura de visitas
│   ├── shell-merchandising/  # Merchandising Shell
│   ├── qualid-merchandising/ # Merchandising Qualid
│   ├── trade-eventos/     # Eventos Trade
│   └── trade-impulso/     # Impulso Trade
├── components/            # Componentes reutilizables
├── services/             # Servicios de negocio
├── types/               # Definiciones de tipos TypeScript
└── utils/               # Utilidades generales

public/
├── icons/               # Iconos de la PWA
├── manifest.json        # Manifiesto PWA
└── sw.js               # Service Worker
```

# **App Name**: Visita Rapida

## Core Features:

- Visit Capture: Capture client visit data, including location and timestamp.
- POP Material Quantification: Quantify the placement of POP (Point of Purchase) materials, with options for Shell and Qualid brands.
- Photo Evidence: Capture 'before' and 'after' photos as evidence of POP material placement.
- Data Export: Export the captured data in a format compatible with the existing database.

## Style Guidelines:

- Primary color: Red (#FF5733) to represent Disbattery Lubricantes.
- Secondary color: Light gray (#F8F9FA) for backgrounds and content separation.
- Accent: Yellow (#FFC107) for highlighting key actions and elements.
- Clean, card-based layout for easy navigation and data input.
- Use clear and recognizable icons for different types of POP materials and actions.

## Original User Request:
Necesito una app para Mercaderistas de una compania llamada Disbattery Lubricantes, que en primera fase capture visitas a campo a clientes, cuantificando el material pop colocado de una lista predeterminada, dividido por marcas (Shell y Qualid), dejando evidencia fotografica de antes y despues. Esto se debe adaptar a una base de datos que ya estamos utilizando y que actualmente estamos capturando datos a traves de un google forms
